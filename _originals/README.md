# Original images

Full-size originals of the pictures in `images/`. The website uses scaled-down copies
(about twice the size at which the page shows them). `torus.png` was used on the
homepage until 2026-10-31.

The Farey-graph logo is now computed by `_logo/farey_logo.py`; `farey-logo.png` and
`farey-logo-animated.gif` here are the earlier hand-made versions.

This folder is not part of the website: GitHub Pages skips files and folders whose
names start with `_`.
